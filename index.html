BCBS Texas — Negotiated Price Transparency

Transparency-in-Coverage machine-readable files (in-network negotiated rates + prescription drugs) published by Blue Cross and Blue Shield of Texas (HCSC).

Source: https://www.bcbstx.com/member/machine-readable-files  ·  Cadence: monthly refresh (source files restated ~monthly)

Start here

New to this project? Read the full how-to first: BCBS Texas Price Transparency Guide (PDF). It explains where the data comes from, the unit of analysis, every inclusion decision, and how to analyze the data in Stata.

  • Unit of analysis: one row of bcbstx_prices.dta = one DISTINCT negotiated price for a procedure in a network, with provider COUNTS (not volume).
  • Scope: BCBS Texas, both coverage segments, Texas providers (NPPES practice state = TX), a 93-code policy-team menu, plus a separate prescription-drug table.
  • Key limits: no claims/volume, no Medicare benchmark, no sub-state geography yet — see the feasibility matrix in 600.

The pipeline (each page is a Stata do-file)

  • 100 Download — Python pulls + filters the MRFs into 01_raw/_extracted/ (guarded; won't re-pull on a rebuild)
  • 200 Management — import CSVs, attach the service menu, build the analytic .dta
  • 300 Labels — plain-English variable + value labels
  • 400 Profiler — coverage, data-quality, descriptive profiling (multi-snapshot ready)
  • 500 Aggregation — price-summary tables (median, dispersion) per service
  • 600 Analysis — price-variation analyses, shoppable case studies, feasibility matrix, expansion menu
  • Help — how this archive + webdoc2 work
