100. Data download

This page documents how the raw files for the THECB_accountability source are fetched into 01_raw/. Raw files are immutable; if you need to clean them, do it in 200_data_management.do.

Files fetched

Each file below is downloaded with Stata's copy command (cross-OS, no shell calls). Edit the list to match the URLs you need for this source.

. * ───────────────────────────────────────────────────────────────────────
. *  Edit this block:  add one line per file to download.
. *  Files are written to 01_raw/; existing files are first moved to _archive.
. *  Leave the lists empty to skip the loop until you have real URLs.
. * ───────────────────────────────────────────────────────────────────────
. 
. local urls

. local localnames

. 
. * Example (uncomment and edit):
. * local urls ///
> *     "https://example.com/data/file1.xlsx" ///
> *     "https://example.com/data/file2.xlsx"
. * local localnames ///
> *     "THECB_accountability_file1.xlsx" ///
> *     "THECB_accountability_file2.xlsx"
. 
. local n  : word count `urls'

. local n2 : word count `localnames'

. 
. if `n' != `n2' di as err "URL/localnames list lengths differ: `n' vs `n2'"

. if `n' == 0    di as txt "  (no URLs configured — edit this do-file to add some)"
  (no URLs configured — edit this do-file to add some)

. 
. local stamp = subinstr("`c(current_date)'", " ", "", .)

. cap mkdir "${raw}/_archive/`stamp'"

. 
. forvalues i = 1/`n' {
  2.     local url  : word `i' of `urls'
  3.     local name : word `i' of `localnames'
  4. 
.     * Stage existing copy to _archive (don't erase yet — keep as fallback)
.     local had_existing 0
  5.     cap confirm file "${raw}/`name'"
  6.     if !_rc {
  7.         di as txt "Archiving existing `name' -> _archive/`stamp'/"
  8.         cap copy "${raw}/`name'" "${raw}/_archive/`stamp'/`name'", replace
  9.         local had_existing 1
 10.     }
 11. 
.     di as txt "Fetching: `url'"
 12.     cap copy "`url'" "${raw}/`name'", replace
 13.     if _rc {
 14.         di as err "  FAILED (rc=`=_rc') -- file not retrieved."
 15.         if `had_existing' {
 16.             di as txt "  -> previous copy in _archive/`stamp'/ still in 01_raw/"
 17.         }
 18.     }
 19.     if !_rc di as txt "  -> ${raw}/`name'"
 20. }

Snapshot source-site documentation

Any PDF codebooks, README pages, or technical notes on the source site go to _documentation/_source_snapshot/ so the cleaning logic stays anchored to a frozen reference even if the source page changes.

. cap mkdir "${docs}/_source_snapshot"

. local docs_urls   ""    // e.g.  "https://example.com/data/codebook.pdf"

. local docs_names  ""    // e.g.  "THECB_accountability_codebook.pdf"

. 
. local nd : word count `docs_urls'

. forvalues i = 1/`nd' {
  2.     local u : word `i' of `docs_urls'
  3.     local n : word `i' of `docs_names'
  4.     cap copy "`u'" "${docs}/_source_snapshot/`n'", replace
  5.     if !_rc di as txt "Snapshot OK: `n'"
  6.     else    di as err "Snapshot FAIL: `u'"
  7. }
