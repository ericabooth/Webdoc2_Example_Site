200. Data management

Mechanical conversion + cleaning for THECB_accountability. Raw stays in 01_raw; analytic output lands in 02_cleaned.

Contents

Pass 0 — bulk convert every raw file to .dta

For every file in 01_raw/ (xlsx/xls/csv/txt/tab/dta/raw), emit one or more .dta files into 01_raw/_converted/ via convertanything in recursive mode. Multi-sheet workbooks produce one .dta per sheet. Subdirectory structure under 01_raw/ is mirrored under _converted/.

_converted/ is wiped first so it stays in exact sync with 01_raw/ on every run. Anything you need to keep across rebuilds belongs in 02_cleaned/, not here.

Toggle this section with global ds_autoconvert "0" in 000_controlfile.do (or scaffold with projectbuilder ..., noautoconvert).

.     dswipe "${converted}"
.     convertanything using "${raw}", recursive saving("${converted}") ///
